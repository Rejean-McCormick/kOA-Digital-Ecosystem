# kOA Digital Ecosystem — Technical Reference

This reference defines ecosystem-level mappings, boundaries and coordination rules. It does not redefine product/platform contracts that already own authoritative state.

## Authorities

- **Konnaxion** — civic/public domain state and product contracts.
- **Orgo** — workflow/work-state and integration-operation contracts.
- **Kristal v5** — epistemic artifacts, validation/recognition, Reader Policy, Runtime Pack semantics.
- **kOA-Linux** — platform profiles, trust/policy/resources, artifact admission, release channels and Release Set contracts.
- **`kristal_runtime`** — local Runtime Pack verification/compatibility/active-state/activation+rollback receipts/runtime health on kOA-Linux.
- **kOA Node Agent** — narrow authorized node-local lifecycle/activation/recovery operations.
- **Koali Spaces** — optional presentation/Space lifecycle and admitted application surfaces.
- **Interaction Kernel** — selected cross-system Profile/protocol layer where explicitly adopted; Konnaxion↔Orgo currently has qualified adoption for two Profile/version pairs.
