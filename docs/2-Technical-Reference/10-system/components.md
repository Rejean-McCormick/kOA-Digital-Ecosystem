# Systems and boundary components

## Konnaxion
Owns civic/public state and DecisionRecords.

## Orgo
Owns workflow/operational work and durable IntegrationOperations.

## Kristal
Owns epistemic artifact semantics, including Structured Epistemic State, Working/Reference Exchanges, validation/recognition, Reader Policy and Runtime Pack semantics.

## kOA-Linux
Owns platform profiles, trust/policy/resources, artifact admission, release-channel and Release Set contracts.

## kristal_runtime
Native kOA-Linux component owning local Runtime Pack verification/compatibility, active Runtime Pack state, activation/rollback receipts and runtime health. It does not own host privilege, governance policy or workflow state.

## kOA Node Agent
Native kOA-Linux component for narrow authorized node-local lifecycle, activation/recovery and privileged host operations. It does not create release or epistemic authority.

## Koali Spaces
Optional presentation/composition subsystem owning shell/routing/Space lifecycle/admitted application surfaces. It does not own participant business or epistemic state.

## Interaction Kernel
Target distributed cross-system Profile/protocol layer where explicitly adopted. It does not silently replace current kOA-Linux internal/component contracts.

## Da’at
Anti-corruption/mapping boundary between ecosystem-facing Kristal requests and Kristal-native contracts.

## SenTient / SemantiK Architect
Retain their own candidate-resolution and NLG responsibilities without acquiring downstream authority.
