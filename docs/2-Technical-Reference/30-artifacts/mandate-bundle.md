# Mandate Bundle

Mandate Bundle is a kOA-owned governance/policy-context artifact where applicable. It does not replace owner-system authorization, Kristal validation/recognition, kOA-Linux Release Set compatibility or Runtime Pack active state.

## Consumption

- Orgo may reference mandate/policy context while authorizing governed work.
- Konnaxion may reference it for civic/application policy where applicable.
- `kristal_runtime` consumes only the authorization/policy references required by its activation contract and does not become governance-policy owner.
- kOA Node Agent executes privileged node operations only with the required authorization references.

For Runtime Pack activation on kOA-Linux, authoritative verification/active-state records remain with `kristal_runtime`; the mandate does not create a separate activation state.
