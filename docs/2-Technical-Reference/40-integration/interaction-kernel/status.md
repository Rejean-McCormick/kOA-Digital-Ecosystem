# Interaction Kernel adoption status

Interaction Kernel is the **target cross-system interoperability layer**, not a blanket replacement for existing platform/product contracts.

## Current interpretation

- Konnaxion↔Orgo target Profiles remain useful ecosystem mappings.
- Da’at remains the target anti-corruption/mapping boundary for IK-facing Kristal work.
- kOA-Linux already defines canonical internal/component interaction types and contracts; explicit adoption/mapping is required before those are described as IK Profiles.
- generic product build/runtime/security qualification does not prove IK conformance.

## Required closure

1. publish product/platform Profile IDs and versions;
2. map payload/authority/idempotency/receipt behavior to owning contracts;
3. provide conformance evidence;
4. preserve legacy bridge compatibility only until the explicit Profile path is qualified.
