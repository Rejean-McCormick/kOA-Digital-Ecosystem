# Language scope and capability matrix

**DOCUMENTED, not a language certification register.** Scope membership is not capability proof. `outside_scope` and `outside_target` are not claims that a language is unsupported everywhere. Unknown is not false. The 25-code union is only the union of documented pilot/focus/active16 scopes, not the complete RGL. The Compendium's 15 model profiles describe engineering examples, not production support.

- Wordbench practical20: 14 focus languages plus Sqi Cze Pol Rus Hrv Gre (diagnostic selection); 15 probes each, 300 potential probes. The 14 focus languages reportedly produced 15 candidate outputs each on 3 November, not reviewed golds.
- Observatory: the same 14-language practical pilot intake, 210 candidates; no canonical release admission inferred.
- diK: 13 target locales, historical `no` retained; the GF `Nor` row is an orientation association only, not an approved locale mapping (`no`/`nb` must not be substituted).
- Phrase Ops active16: policy 128 technical probes, 121 advertised, 7 disabled. No fresh execution or per-language linguistic review established here.
- Defluens: 28 automated FR/EN candidates, 14 parity pairs, zero human linguistic reviews in the reported 5 November run; no release or activation reported for that run.
- Spek: FR/EN/IT fixture output, not certified SA output or publication permission.
