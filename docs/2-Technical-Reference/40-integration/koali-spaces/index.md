# Koali Spaces integration

Koali Spaces is an optional presentation/composition subsystem. The owning Koali repository is authoritative for its Surface Layer, Space model, runtime registration and UI/security contracts.

## Ecosystem rules

- presentation does not transfer business authority;
- Space activation does not activate a Kristal Runtime Pack;
- runtime registration/readiness is not owner-domain authorization;
- lifecycle requests use the applicable owner/broker path;
- Kristal views preserve status/certainty/authority/Reader Policy labels;
- owner applications retain internal route/domain authority.

Current evidence includes a real Konnaxion pilot. Every additional product integration remains explicit and separately evidenced.
