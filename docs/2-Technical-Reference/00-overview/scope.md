# Scope

This repository is authoritative only for ecosystem-level mappings, cross-system invariants and optional correlation evidence.

It may document:

- owner boundaries;
- cross-system contracts/Profiles and adoption status;
- how product/platform artifacts are referenced;
- lifecycle separation;
- kOA-Linux release-channel/Release Set mapping;
- `kristal_runtime` versus kOA Node Agent responsibility;
- Koali Spaces presentation boundary;
- implementation-status gaps between owners.

It does not redefine:

- Konnaxion civic models;
- Orgo Task/Case/Workflow internals;
- Kristal schemas/epistemic semantics;
- kOA-Linux platform component/artifact/release contracts;
- Koali Spaces Surface Layer/Space model contracts;
- SemantiK Architect internal NLG contracts.
