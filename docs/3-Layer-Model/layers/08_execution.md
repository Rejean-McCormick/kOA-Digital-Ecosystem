# Layer 08 — Execution

**Layer status:** Conceptual layer

## Function

Execution turns authorized decisions or operational intent into work while preserving domain ownership.

## Mapping

- Orgo owns operational/workflow execution represented in Orgo.
- Konnaxion owns civic/governance state and can issue governed execution intent through an adopted boundary.
- Kristal owns epistemic/reference artifacts, not general workflow execution.
- `kristal_runtime` owns local Runtime Pack verification/active-state/receipts on kOA-Linux.
- kOA Node Agent performs narrow authorized privileged node-local transitions.
- Koali Spaces owns presentation/Space lifecycle only.

`accepted` delivery is not equivalent to business success.
