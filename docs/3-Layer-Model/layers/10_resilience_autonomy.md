# Layer 10 — Resilience / Autonomy

**Layer status:** Conceptual layer

## Function

Preserve safe local operation under connectivity/infrastructure constraints through verified local artifacts, explicit trust, reproducible evidence and rollback.

## Relevant owners/artifacts

| Item | Role |
|---|---|
| Runtime Pack | Kristal runtime projection with explicit source epistemic status |
| Release Set | kOA-Linux compatibility binding across release channels |
| `kristal_runtime` | local Runtime Pack verification/active-state/rollback/runtime health |
| kOA Node Agent | narrow privileged node-local lifecycle/recovery transition |
| Koali Spaces | optional presentation continuity and Space lifecycle |
| Build evidence | reproducibility/correlation, non-authoritative |

Fail-closed behavior applies to the transition being protected. Failed activation verification blocks unsafe activation; it does not imply every Working Exchange was forbidden from being compiled.
