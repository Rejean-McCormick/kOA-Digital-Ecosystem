# 01 — Authority and ownership

**Status:** `TARGET_DESIGN`.

Skope/EncyK owns scoped research; Mediatheque owns source custody. Framework + Kit own canonical semantic profile and authoring workspaces. Konnaxion owns civic DecisionRecords; Orgo owns durable Cases and Tasks. UCKK owns its institutional Moodle projections; SemantiK owns language realization and RuntimeSets under separate rules. Konfid issues scoped decisions but each owner enforces at its own PEP. Public sites and C0 present approved, derived descriptions only.

Any owner conflict is a blocking design decision; data must not be written across owners by a shared UI or external adapter.
